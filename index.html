Barcode Symbologies Reference Guide

This software uses bwip-js to generate production-ready barcodes. Below is a quick guide to selecting the right barcode symbology for your project:

Symbology Category Best Used For Data Format Rules
Code 128 1D Linear Shipping, inventory, asset tags, products Full 128 ASCII text & numbers
QR Code 2D Matrix Mobile scanning, website links, WiFi, vCards UTF-8 text, URLs, binary data
EAN-13 Retail International retail consumer items Exact 12 or 13 numeric digits
UPC-A Retail North American retail checkout Exact 11 or 12 numeric digits
Data Matrix 2D Matrix Small parts, PCBs, pharmaceutical packages High-density ASCII & binary data
PDF417 2D Stacked Driver licenses, government IDs, boarding passes Large payload text & binary data
ITF-14 Retail/Carton Master shipping cartons, outer boxes Exact 14 numeric digits with frame
GS1-128 Logistics Supply chain containers with batch & exp date GS1 AIs like (01)GTIN(10)LOT(17)EXP
